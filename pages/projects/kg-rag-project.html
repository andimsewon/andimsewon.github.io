KG-RAG: Knowledge-Graph-Augmented Retrieval

PyTorch LangChain RAG

Problem

Standard retrieval-augmented generation retrieves flat text chunks by embedding similarity alone, which gives large language models little structured relational context. That limits factual accuracy and multi-hop reasoning — questions that require chaining facts across multiple connected entities.

Approach

Designing and implementing knowledge graph–enhanced retrieval-augmented generation (RAG) architectures to improve factual accuracy and multi-hop reasoning capabilities in large language models, at the Natural Language Learning Lab, Jeonbuk National University (Advisor: Prof. Hyun-je Song).

  • Developing graph-based retrieval pipelines that integrate structured knowledge (knowledge graphs) with neural embedding spaces, implemented using PyTorch and LangChain frameworks
  • Implementing multi-hop reasoning mechanisms over knowledge graphs to enable complex query answering in domain-specific applications, with focus on improving retrieval precision and model grounding
  • Conducting systematic ablation studies on embedding integration techniques (entity linking, relation extraction, graph embedding methods) to optimize retrieval performance and evaluate trade-offs between accuracy and computational efficiency

Result

Multi-hop reasoning over a knowledge graph to improve factual grounding in LLM outputs. A manuscript describing this work — "Knowledge Graph–Enhanced Retrieval-Augmented Generation for Multi-Hop Reasoning in Large Language Models" — is in preparation with the Natural Language Learning Lab.

My Role

I designed and implemented the knowledge-graph retrieval pipeline and multi-hop reasoning mechanism as an undergraduate researcher under Prof. Hyun-je Song.

Tech Stack: PyTorch, LangChain
