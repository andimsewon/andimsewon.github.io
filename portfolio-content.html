WaggleNet — LoRa & MQTT 기반 벌통 내부·외부 동시 모니터링

프로젝트 상세
  • 내·외부 동시 환경 모니터링 LoRa–MQTT 듀얼 스코프, ESP32-S3 기반 워커/마스터 구조
  • 센서: DHT22, LDR, GPS; 3분 주기 JSON → LoRa → MQTT → SQLite/클라우드
  • 전송거리 110m(LOS)/95m(차폐), LoRa 전파 <1s, 모듈당 $10–15, 2개월 필드 운용
  • Flutter 모바일 실시간 대시보드 + Firebase FCM 알림
  • 논문: arXiv: https://arxiv.org/abs/2512.07408
스택: C++, Python, MQTT, SQLite, Flutter, Firebase · 프로토콜: LoRa, MQTT Pub/Sub
07 / WaggleNet
상세

WaggleNet — 시스템 아키텍처

  • 토폴로지: ESP32-S3 워커(센싱) ↔ LoRa 게이트웨이 ↔ MQTT 브로커 ↔ 모바일/DB
  • 프로토콜: LoRa(저전력~장거리) + MQTT(Pub/Sub, QoS1)
  • 데이터 경로: 센싱(3분 주기 JSON) → LoRa → 게이트웨이 파싱 → MQTT 토픽 발행 → SQLite/클라우드 적재
  • 모바일: Flutter 실시간 스트림 + Firebase FCM 임계치 알림
  • 센서: DHT22(온습도), LDR(조도), GPS(위치)
8 노드(필드) LOS 110m / 차폐 95m LoRa 전파 <1s $10–15 / 노드

WaggleNet — 실험 결과 & 개선점

  • 거리·지연: 개활지 110m/도심 차폐 95m까지 패킷 안정 수신, LoRa 홉 지연 <1s
  • 신뢰성: MQTT QoS1 + 재전송 로직으로 누락률 저감

  • 개선점: 저전력 최적화(딥슬립/샘플링 주기 적응), LoRa 채널 혼잡 시 주파수 호핑
