KG-RAG: 지식그래프 기반 검색 증강 생성

PyTorch LangChain RAG

Problem

일반적인 검색 증강 생성(RAG)은 임베딩 유사도만으로 평평한(flat) 텍스트 조각을 검색하기 때문에, LLM에 구조화된 관계 정보를 거의 제공하지 못합니다. 이는 사실적 정확도와, 여러 개체를 연결해야 답할 수 있는 멀티홉 추론 능력을 제한합니다.

Approach

전북대학교 Natural Language Learning Lab 학부연구생으로 활동하며(2025년 2월–2026년 2월, 지도교수: 송현제), 대규모 언어 모델의 사실적 정확도와 멀티홉 추론 능력을 높이기 위한 지식그래프 기반 RAG 아키텍처를 설계·구현했습니다.

  • 구조화된 지식과 신경망 임베딩 공간을 통합하는 그래프 기반 검색 파이프라인을 개발했습니다 (PyTorch, LangChain)
  • 도메인 특화 복합 질의응답을 위한 지식그래프 기반 멀티홉 추론 메커니즘을 구현했습니다
  • 임베딩 통합 기법에 대한 체계적인 어블레이션 연구로 정확도와 연산 효율성 간의 트레이드오프를 평가했습니다

Result

지식그래프를 활용한 멀티홉 추론으로 LLM 출력의 사실적 근거를 강화했습니다. Natural Language Learning Lab에서 2025년 2월부터 2026년 2월까지 수행한 이 연구를 바탕으로 원고를 준비하고 있습니다.

My Role

2025년 2월부터 2026년 2월까지 송현제 교수님 지도 하에 학부연구생으로서 지식그래프 검색 파이프라인과 멀티홉 추론 메커니즘을 직접 설계·구현했습니다.

기술 스택: PyTorch, LangChain
