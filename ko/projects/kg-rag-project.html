KG-RAG: 지식그래프 기반 검색 증강 생성

PyTorch LangChain RAG

Problem

일반적인 검색 증강 생성(RAG)은 임베딩 유사도만으로 평평한(flat) 텍스트 조각을 검색하기 때문에, LLM에 구조화된 관계 정보를 거의 제공하지 못합니다. 이는 사실적 정확도와, 여러 개체를 연결해야 답할 수 있는 멀티홉 추론 능력을 제한합니다.

Approach

전북대학교 Natural Language Learning Lab(지도교수: 송현제)에서, 대규모 언어 모델의 사실적 정확도와 멀티홉 추론 능력을 높이기 위한 지식그래프 기반 RAG 아키텍처를 설계·구현하고 있습니다.

  • 구조화된 지식(지식그래프)과 신경망 임베딩 공간을 통합하는 그래프 기반 검색 파이프라인 개발 (PyTorch, LangChain 활용)
  • 도메인 특화 응용에서 복합 질의 응답을 가능하게 하는 지식그래프 기반 멀티홉 추론 메커니즘 구현 — 검색 정밀도와 모델 근거(grounding) 향상에 중점
  • 임베딩 통합 기법(엔티티 링킹, 관계 추출, 그래프 임베딩 방법)에 대한 체계적인 어블레이션 연구를 통해 검색 성능을 최적화하고 정확도와 연산 효율성 간의 트레이드오프 평가

Result

지식그래프를 활용한 멀티홉 추론으로 LLM 출력의 사실적 근거를 강화합니다. 이 연구를 다룬 논문 "Knowledge Graph–Enhanced Retrieval-Augmented Generation for Multi-Hop Reasoning in Large Language Models"을 Natural Language Learning Lab과 함께 준비 중입니다.

My Role

송현제 교수님 지도 하에 학부연구생으로서 지식그래프 검색 파이프라인과 멀티홉 추론 메커니즘을 직접 설계·구현했습니다.

기술 스택: PyTorch, LangChain
