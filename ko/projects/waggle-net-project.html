WaggleNet – LoRa 및 MQTT 기반 내부·외부 벌통 환경 모니터링 시스템

LoRa MQTT Edge IoT
클릭하여 논문 보기

Purdue University Korean AI Square Summer Program 참여 프로젝트로, 벌통 내·외부를 동시에 모니터링하는 저비용·확장형 스마트 양봉 IoT 시스템을 구축했습니다.

기존 스마트 벌통은 내부 온습도에 편중되거나 고가의 GSM/LTE 통신에 의존해 규모 확장이 어렵고 지연이 컸습니다. WaggleNet은 Heltec Wi‑Fi LoRa 32 (V3) 노드와 LoRa–MQTT 하이브리드 아키텍처를 사용해 벌통 내부·외부 환경을 실시간 수집·전송합니다.

워커 노드(DHT22, LDR, GPS)는 3분 간격으로 샘플링하여 LoRa로 마스터 노드에 전송하고, 마스터는 UTC 타임스탬프를 추가해 JSON을 MQTT 서버로 전달, SQLite 기반 클라우드 DB에 저장합니다. Flutter 앱에서 온도·습도·조도·위치를 실시간 시각화하며, 임계치 초과 시 Firebase Cloud Messaging으로 경보를 발송합니다.

Purdue 실험 장소(KSW 빌딩)와 인근 양봉장(South 525 West)에서 필드 테스트를 수행했으며, LoRa 링크는 개방 환경 ~110m, 장애물 환경 ~95m까지 안정적으로 유지되었습니다. 목재 벌통 내부에서도 통신 신뢰성을 확인했습니다.

모듈형 설계, 낮은 B.O.M(노드당 약 $10–15), 소형 하드웨어, 모바일 접근성을 결합해 정밀 양봉·스마트 농업에 적합한 플랫폼임을 입증했습니다. 향후 온디바이스 이상 감지, 하드웨어 소형화, 적응형 라우팅을 통해 자율성을 강화할 계획입니다.

기술 스택: 하드웨어: ESP32-S3 (Heltec Wi-Fi LoRa 32 V3), DHT22, LDR, GPS (NEO-6M) | 소프트웨어: C++, Python, MQTT, SQLite, Flutter, Firebase | 통신 프로토콜: LoRa (433/868/915MHz), MQTT Publish/Subscribe
